# SteamKeys Store

Plataforma de venda de chaves digitais para jogos da Steam, com entrega rápida e pagamentos integrados.

## Funcionalidades

- Carrinho de compras com aplicação de cupons
- Múltiplos métodos de pagamento (PIX, cartão, boleto, criptomoedas)
- Entrega rápida de chaves após confirmação de pagamento
- Sistema anti-fraude

## Tecnologias

HTML5, CSS3, JavaScript e PHP 8.0+ com framework JSON.
